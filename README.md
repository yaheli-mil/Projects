## 🌟 סקירה כללית

אתר זה מכיל אוסף של פרויקטים אינטראקטיביים הבנויים בטכנולוגיות web נקיות (HTML, CSS, JavaScript). האתר מעוצב בעברית עם תמיכה מלאה בכיוון RTL.

## 🎮 פרויקטים

### משחק הצבעים 🎨

משחק אינטראקטיבי המאתגר את מהירות התגובה והריכוז שלכם!

**תכונות עיקריות:**
- 🎯 מטרה: להקליד את הצבע שהמילה צבועה בו (ולא את המילה עצמה)
- ⏱️ מנגנון זמן דינמי שמתאים עם ההתקדמות
- 🎨 כל אות צבועה בגוון שונה לאתגר נוסף
- 🔤 פונטים משתנים בכל סיבוב
- 💾 שמירת שיא אישי ב-LocalStorage
- ⚡ בונוס זמן על תשובה נכונה
- 📊 מערכת ניקוד ומעקב אחר שיא

**צבעים זמינים במשחק:**
אדום, כחול, ירוק, צהוב, סגול, ורוד, כתום, שחור, חום, אפור, תכלת

**קבצים:**
- `color-game.html` - הגרסה העדכנית של המשחק
- `color-game/old.html` - הגרסה הישנה של המשחק

### מערכת ניהול משימות 📅

מערכת חכמה לניהול משימות שבועיות עם ממשק נוח וידידותי.

**תכונות עיקריות:**
- 📆 ארגון משימות לפי ימים בשבוע
- 💾 שמירה אוטומטית ב-LocalStorage
- 🔄 איפוס אוטומטי בתחילת כל שבוע
- ✨ עיצוב מודרני ותגובתי (Responsive)
- ❌ מחיקת משימות בקלות
- 📱 תמיכה מלאה במובייל

**תכונות טכניות:**
- זיהוי שבוע אוטומטי לפי תקן ISO
- מעקב אחר מספר השבוע והשנה
- שמירה מקומית של כל המשימות
- ממשק דו-עמודות (טופס הוספה + לוח משימות)

**קבצים:**
- `tasks.html` - הגרסה העדכנית של המערכת
- `tasks/old.html` - הגרסה הישנה של המערכת

## 🛠️ טכנולוגיות

הפרויקט בנוי עם טכנולוגיות web טהורות:

- **HTML5** - מבנה הדפים
- **CSS3** - עיצוב וסטיילינג
  - Flexbox & CSS Grid לפריסה
  - CSS Variables לניהול צבעים
  - Transitions & Animations לאפקטים
  - Media Queries לעיצוב רספונסיבי
- **Vanilla JavaScript** - לוגיקה ואינטראקציות
  - LocalStorage API לשמירת מידע
  - DOM Manipulation
  - Event Handling
  - Timer & Timeout APIs

**פונטים:**
- Rubik - פונט ראשי (Google Fonts)
- פונטים נוספים למשחק הצבעים: Amatic SC, Rubik Bubbles, Rubik Glitch, Secular One ועוד

```

│

├── color-game.html         # משחק הצבעים (גרסה חדשה)
├── tasks.html              # מערכת משימות (גרסה חדשה)
├── 404.html                # עמוד שגיאה 404
│
├── color-game/             # תיקיית משחק הצבעים
│   └── old.html            # גרסה ישנה של המשחק
│
└── tasks/                  # תיקיית מערכת המשימות
    └── old.html            # גרסה ישנה של המערכת
```

## 🚀 הרצה מקומית

1. שכפלו את הריפוזיטורי:
```bash
git clone https://github.com/yaheli-mil/Projects.git
```

2. פתחו את הקובץ `index.html` בדפדפן או השתמשו בשרת מקומי:
```bash
# עם Python 3
python -m http.server 8000

# עם Node.js (http-server)
npx http-server

# עם PHP
php -S localhost:8000
```

3. פתחו את הדפדפן בכתובת: `http://localhost:8000`

## 🎯 שימוש

### משחק הצבעים
1. גשו לדף המשחק דרך עמוד הבית או ישירות ל-`color-game.html`
2. לחצו על "התחל משחק"
3. הקלידו את שם הצבע שהמילה צבועה בו (לא את המילה עצמה!)
4. אין צורך ללחוץ Enter - התשובה נבדקת אוטומטית
5. נסו להשיג את השיא האישי שלכם!

### מערכת ניהול משימות
1. גשו לדף המערכת דרך עמוד הבית או ישירות ל-`tasks.html`
2. הזינו תיאור משימה
3. בחרו יום ביצוע
4. לחצו "הוסף לרשימה"
5. המשימות נשמרות אוטומטית
6. למחיקת משימה - לחצו על ה-X
