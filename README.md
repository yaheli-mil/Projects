## 🌟 סקירה כללית

אתר זה מכיל אוסף של פרויקטים אינטראקטיביים הבנויים בטכנולוגיות web נקיות (HTML, CSS, JavaScript). האתר מעוצב בעברית עם תמיכה מלאה בכיוון RTL.

## 🎮 פרויקטים

### משחק הצבעים 🎨

משחק אינטראקטיבי המאתגר את מהירות התגובה והריכוז שלכם!

**תכונות עיקריות:**
- 🎯 מטרה: להקליד את הצבע שהמילה צבועה בו (ולא את המילה עצמה)
- ⏱️ מנגנון זמן דינמי שמתאים עם ההתקדמות
- 🎨 כל אות צבועה בגוון שונה לאתגר נוסף
- 🔤 פונטים משתנים בכל סיבוב
- 💾 שמירת שיא אישי ב-LocalStorage
- ⚡ בונוס זמן על תשובה נכונה
- 📊 מערכת ניקוד ומעקב אחר שיא

**צבעים זמינים במשחק:**
אדום, כחול, ירוק, צהוב, סגול, ורוד, כתום, שחור, חום, אפור, תכלת

**קבצים:**
- `color-game.html` - הגרסה העדכנית של המשחק
- `color-game/old.html` - הגרסה הישנה של המשחק

### מערכת ניהול משימות 📅

מערכת חכמה לניהול משימות שבועיות עם ממשק נוח וידידותי.

**תכונות עיקריות:**
- 📆 ארגון משימות לפי ימים בשבוע
- 💾 שמירה אוטומטית ב-LocalStorage
- 🔄 איפוס אוטומטי בתחילת כל שבוע
- ✨ עיצוב מודרני ותגובתי (Responsive)
- ❌ מחיקת משימות בקלות
- 📱 תמיכה מלאה במובייל

**תכונות טכניות:**
- זיהוי שבוע אוטומטי לפי תקן ISO
- מעקב אחר מספר השבוע והשנה
- שמירה מקומית של כל המשימות
- ממשק דו-עמודות (טופס הוספה + לוח משימות)

**קבצים:**
- `tasks.html` - הגרסה העדכנית של המערכת
- `tasks/old.html` - הגרסה הישנה של המערכת

### מיפוי שנות שירות בתק״מ וצ'אט בוט AI 🌿

פורטל מקיף ואינטראקטיבי למיפוי, סינון והכוונה עבור שנות שירות בתק״מ (כפרי נוער ופנימיות), המעוצב בשפת עיצוב מינימליסטית ושקטה בהשראת Apple (Apple Minimalist Design), ומצויד ביועץ AI אישי חכם.

**תכונות עיקריות:**
- 🎯 **סינון חכם ומותאם אישית:** מיון קפדני לפי קריטריונים ברורים – קומונה גדולה (10+ ש״שינים ומעלה), מודל 'אח בוגר' ומלווה ללא תפקידי משמעת, פריסה במרכז, בשרון ובצפון.
- 🏆 **13 המסגרות המובילות:** כרטיסי עדיפות עליונה לפתיחה ראשונה (הכפר הירוק, ויצ״ו הדסים, כפר גלים, נירים, מוסינזון, עתיד רזיאל ועוד).
- 📋 **טבלת מיפוי מלאה (30 מסגרות):** סינון מהיר לפי אזור (צפון, שרון, מרכז), סוג מסגרת (כפרי נוער / פנימיות), משק חקלאי פעיל, וגודל קומונה (15+).
- 🔍 **שקיפות מלאה (18 מסגרות שנפסלו):** פירוט מדויק ומנומק מדוע מוסדות נפסלו (פחות מ-10 ש״שינים, ופסילת אלוני יצחק עקב היותו בית הספר של יהלי).
- 💡 **הכנה למיונים ולכנסים:** 8 שאלות מפתח קריטיות לראיונות פנימייה ולוח תאריכי כנסים מרוכז ומסודר.
- 🤖 **ש״ש-בוט AI (צ'אט פופ-אפ אינטראקטיבי):**
  - חלונית צ'אט צפה מעוצבת בסגנון Apple Drawer (אינה תופסת מסך מלא, ניתנת לפתיחה וסגירה מהירה).
  - מחובר ישירות ל-**Groq API** (מודלים מובילים כדוגמת `openai/gpt-oss-120b`, `openai/gpt-oss-20b` ו-`qwen/qwen3.8-27b`) באמצעות פונקציית Netlify Serverless מאובטחת.
  - מהירות מענה גבוהה במיוחד (LPU Inference) עם Rate Limit נדיב ומנוע ידע מקומי עצמאי (Smart Local Knowledge Engine) המבטיח מענה שוטף ומדויק ב-100% מהמקרים.

**קבצים:**
- `takam.html` - פורטל שנות השירות
- `netlify/functions/chat.js` - פונקציית Serverless לחיבור מאובטח מול Groq API
- `netlify.toml` - קובץ תצורת הפריסה והפניות ה-API של Netlify

## 🛠️ טכנולוגיות

הפרויקט בנוי בטכנולוגיות web מודרניות ונקיות:

- **HTML5 & CSS3** - עיצוב סמנטי, רספונסיבי ומלוטש בהשראת Apple Design System.
  - Flexbox & CSS Grid לפריסות כרטיסים וטבלאות מתקדמות
  - CSS Variables לניהול שפה עיצובית אחידה
  - Backdrop Filter ואפקטי Glassmorphism שקטים
  - תמיכה מלאה בכיווניות עברית (RTL) ובמכשירים ניידים
- **Vanilla JavaScript** - לוגיקה מהירה ללא תלות בספריות חיצוניות כבדות.
  - מנועי חיפוש וסינון רב-שכבתיים בזמן אמת
  - LocalStorage API לשמירת נתונים מקומית
  - Fetch API לתקשורת אסינכרונית
- **AI & Serverless Backend**
  - **Groq API** (OpenAI GPT-OSS 120B / 20B & Qwen 3.8 27B) לעיבוד שפה טבעית במהירות שיא ובתבונה גבוהה
  - **Netlify Serverless Functions** (Node.js) לניהול מפתחות סביבה מאובטחים (`process.env.GROQ_API_KEY`)
  - **Failover Architecture** - מעבר אוטומטי בין מודלים ומנוע ידע מקומי (Zero Downtime)

**פונטים:**
- Rubik & SF Pro - פונטים ראשיים (Google Fonts & Apple System Fonts)
- פונטים נוספים למשחק הצבעים: Amatic SC, Rubik Bubbles, Rubik Glitch, Secular One ועוד

## 🚀 הרצה מקומית

1. שכפלו את הריפוזיטורי:
```bash
git clone https://github.com/yaheli-mil/Projects.git
```

2. פתחו את הקובץ `index.html` בדפדפן או השתמשו בשרת מקומי:
```bash
# עם Python 3
python -m http.server 8000

# עם Node.js (http-server)
npx http-server

# עם PHP
php -S localhost:8000
```

3. פתחו את הדפדפן בכתובת: `http://localhost:8000`

## 🎯 שימוש

### משחק הצבעים
1. גשו לדף המשחק דרך עמוד הבית או ישירות ל-`color-game.html`
2. לחצו על "התחל משחק"
3. הקלידו את שם הצבע שהמילה צבועה בו (לא את המילה עצמה!)
4. אין צורך ללחוץ Enter - התשובה נבדקת אוטומטית
5. נסו להשיג את השיא האישי שלכם!

### מערכת ניהול משימות
1. גשו לדף המערכת דרך עמוד הבית או ישירות ל-`tasks.html`
2. הזינו תיאור משימה
3. בחרו יום ביצוע
4. לחצו "הוסף לרשימה"
5. המשימות נשמרות אוטומטית
6. למחיקת משימה - לחצו על ה-X
